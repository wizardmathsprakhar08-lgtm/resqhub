## 3. Confirmed Reference Features vs Proposed ResQHub Enhancements

### Confirmed Features in Reference
1. SQLite-backed emergency contacts with a hard limit of 5 contacts.
2. Manual contact input and device contact picker (`ContactsContract`).
3. View, call, and delete contacts.
4. Custom emergency text message saved locally.
5. Foreground service monitoring for accelerometer shake detection (`magnitude > 90`, 5s debounce).
6. High accuracy location retrieval with a 10s fallback timeout.
7. Google Maps coordinates link (`https://maps.google.com/maps?q=<lat>,<lon>`).
8. SMS dispatch to all contacts with personalized greeting (`"Hey, <name>..."`).
9. National emergency helplines (Ambulance 108, Fire 101, Police 100, Disaster 1078, Gas Leak 1906).
10. First aid guide for Burns, Fractures, and Bleeding.
11. How-to-use user guide.

### Proposed & Required ResQHub Improvements
1. **Deliberate SOS Activation & Countdown:**
   - In the reference app, shaking immediately fires SMS messages without any grace period to cancel an accidental trigger.
   - ResQHub introduces an SOS State Machine (`idle` -> `confirming` [5s countdown with audible/haptic cancel option] -> `locating` -> `sending` -> `sent` / `partial_failure` / `failed`) and a prominent press-and-hold home button.
2. **Server-Mediated Delivery & Twilio Backend:**
   - The reference app sends SMS directly from the device's SIM card via `SmsManager`. On modern Android (API 33+), `SEND_SMS` is restricted for third-party apps and carrier charges apply.
   - ResQHub introduces a Python FastAPI backend with Twilio SMS integration, delivery status webhooks, idempotency keys, and offline native SMS fallback.
3. **Alert History & Active Alert Tracking:**
   - The reference app does not log past alerts. ResQHub records all alert events locally in SQLite and server-side in the backend database, with coordinates, timestamps, and delivery statuses.
4. **Phone Number Normalization & Validation:**
   - The reference app validates strictly `number.length() == 10`. ResQHub supports standard national and E.164 international phone formats, stripping whitespace and dashes.
5. **Modern Design System & Privacy:**
   - ResQHub replaces raw Android XML with a custom design system: Midnight Navy & Deep Teal primary palette, Coral emergency actions, clear contrast, accessible touch targets, and secure storage via `expo-secure-store`.
